## 3. Class B measured red before it measured green / B류가 초록 전에 빨강으로 재어졌다

D010 said GIOP 1.1 wide text was unmeasurable here — omniORBpy cannot read its
own — and that the first step was a JacORB-at-1.1 fixture. The fixture took
one batch and found, the same hour, that at 1.1 we write a byte-order mark
JacORB neither writes nor strips: its user got `U+FEFF` + text, and its echo of
our mark came back as data that **our reader then stripped**, so
`spike-interop`'s "wstring round-tripped under GIOP 1.1" had been green with
the peer's user seeing the wrong value. Fixed the same day; the fixture asserts
the version from bytes and counts wire units so the masking cannot recur; and
JacORB reads an unmarked 1.1 value in *message* order, which contradicts a
literal reading of §9.3.1.6's "neither → big-endian" bullet — the code follows
the only 1.1 peer it can measure and says so.

That is the previous session's recurring finding once more — *a convention both
ends apply cannot be refuted by a round trip* — with a new corollary: **a
convention one end applies on read can hide the other end's defect on write.**

잴 수 없다던 B류 행이 픽스처 하나로 재어졌고, 첫 측정은 빨강이었다: 우리 리더가
피어의 되돌아온 데이터를 표식으로 벗겨내어 왕복이 초록이었다.

## 6b. The second wave: "the remaining parts too" / 둘째 웨이브: "남은 부분도"

Six agent batches over the day's own "found and not fixed" lines, plus the
coordinator's B-row audit. What it kept finding:

- **The oracle that separates the two forward statuses exists after all.**
  omniORB 4.3.4 restarts at the original after a *temporary* forward's target
  dies (§9.6 "shall") and stays on the dead address after a *permanent* one
  (§9.6 "may replace") — through which a server downgrading status 4 to 3 goes
  red. Ours: `Connection` errs under both (holds no original), `Reference`
  re-asks under both. Neither distinguishes; the peer does.
- **A third wire defect of the day's recurring class.** A union TypeCode's
  bare `default:` member wrote no label bytes; our own decode, omniORB and
  JacORB all refused it, and nothing was red because every gate ran both ends
  through one encoder. Found by adding golden 29 for a *different* union
  shape. Fix: zeros at the discriminator's width, ignored on read — measured
  as the only form both peers accept in both byte orders (JacORB reads the
  slot as one octet that must be 0; omniORB ignores it).
- **1.1 `wchar` was never wrong** — two octets in the message's order, U+FEFF
  as data — and it took a fixture to say so instead of a doc paragraph saying
  "unmeasured". No code change; nine captures.
- **The property sweep now crosses AnyJSON**: 12,928 crossings over four
  corpora, 0 findings, two negative controls red. The gap 1b6b4c8 named is
  closed and it found nothing — the honest result.
- **The coordinator's own gate caught its own text.** The B3 SSLIOP probe
  grepped `'sslTP present'` out of an `ImportError` traceback that echoes the
  source line, and reported the module present. Caught on its first run by
  reading the harness's line against the shell's; the probe is an exit code
  now. The class the session record calls "a grep that caught its own
  comment", on the person who had just written the record.
- Small ones: the live marshalling error names the argument; a
  labelled-and-`default:` union branch is kept by all three emitters (the Rust

Still open after both waves: the registry folds `case 2: default:` where

## 6c. The third wave: what the second one left / 셋째 웨이브: 둘째가 남긴 것

Four batches, all cut off once by a usage limit and resumed in their intact
worktrees (the work was on disk; "trust the filesystem over your memory").

- **Both our clients now behave as omniORB does under the two forward
  statuses.** `Connection` keeps `origin()` and restarts there when a
  temporary forward's target fails with the request provably unsent
  (CloseConnection / write failure / poisoned at entry — never on unknown
  completion, which stays an honest error); a permanent forward replaces the
  origin. `Reference` caches a temporary forward (one round trip per call,
  was two), restarts the same way, re-points on permanent. Ten cells green
  beside omniORB's, both byte orders. Decided on the record's recommendation.
- **The union member list is the peer's.** A labelled-and-`default:` branch
  expands to omniidl's shape — one member per label plus a labelless default

  Rust stubs unchanged. What it left: the §5.3 differ compares the default by
  label, not by role.
- **`wide.idl` from our own stack.** The real Rust server writes JacORB's
  recorded reply octets in both orders; our 1.1 request is octet-for-octet
  JacORB's. And it found the day's fourth wire defect: **U+FEFF as a 1.2

  readers strip it as a mark. Recorded, not gated, measured before fixing.
- **`--dry-run-handle`**: the CLI dry run holds a parsed, undialed reference;

## 6d. Two closing batches / 닫는 배치 둘

- **U+FEFF as a 1.2 `wchar` crosses both ways now** — measured against
  JacORB's reader *first* (13 forms × 2 message orders: it honours a mark in
  either order and removes it), then the writer marks a unit that is itself a
  mark (`04 fe ff fe ff`) and the reader takes a bare mark as the unit (a
  wchar is never empty, so only a bare writer produces it). JacORB's own
  writer and reader still disagree on that code point — the peer's, out of
  reach.
- **The §5.3 differ compares union members by role.** And it corrected the
  brief: "adding a default is compatible" was a guess; the generated stub
  showed omniORB reads *no member* after an unlabelled discriminator and
  raises nothing, so adding a default is conditionally breaking — the silent
  class §5.3 exists for. A retyped default behind an inserted case, which the
  positional differ missed, is a corpus pair now.
- **CI caught what macOS cannot**: `forward_restart`'s scripted target dropped
  its listener together with the socket, and on Linux the client's redial
  raced that drop into ECONNRESET (2 of 5 runs). Not reproducible here; fixed
  by ordering (listener gone before CloseConnection is sent) and measured by
  CI's next run — 5 of 5. A first attempt (drain the socket) was wrong and
  deadlocked the redial; reverted before commit.
